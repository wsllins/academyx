**Como** aluno,
**quero** marcar minha sessão de estudos,
**para** gerir meu tempo de acordo com as disciplinas que estou focando.

### Critérios de aceitação
* [ ] O sistema deve permitir o aluno escolher a disciplina que quer estudar no momento.
* [ ] O aluno deve conseguir inicializar o timer para salvar a sua sessão de estudos da disciplina que escolheu.
* [ ] O aluno deve conseguir para o timer em qualquer momento.
* [ ] O aluno pode editar seu tempo de estudo adicionando ou removendo tempo de qualquer disciplina.

### Tasks
* [ ] T01 - Desenvolver a interface de foco
* [ ] T02 - Implementar o timer de estudos
* [ ] T03 - Implementar edição manual do tempo de estudo
* [ ] T04 - Integrar e validar o registro das sessões
